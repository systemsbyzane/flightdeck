# Flightdeck Automations

Read `references/automation-method.md` before creating, changing, or evaluating
scheduled work.

Treat Hub YAML files as disabled, reviewable specifications. A real schedule
exists only when it is created and verified through the current Codex automation
capability. Keep jobs read-only by default, record source freshness, use stable
finding keys, and report new, resolved, persistent, and blocked deltas.

Do not infer authority to edit repositories, clone, build, commit, push, create
or comment on pull requests, rerun workflows, mutate environments, submit
compliance artifacts, accept risk, or close POA&M items.
