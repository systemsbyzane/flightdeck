# Source ledger

For every material source record:

- source ID
- owner or publisher
- path or URL
- source type
- publication, commit, or observation date
- access date
- authority and scope
- claim supported
- classification: observed fact, configuration, documentation, inference,
  assumption, contradiction, or unknown
- freshness and confidence

Prefer primary and authoritative sources. Timestamp live observations and state
the account, environment, or context without exposing credentials. Expose
contradictions rather than averaging them away.
