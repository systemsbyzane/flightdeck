# Review readiness

- Confirm the change is in the owning repository.
- Read repository review instructions.
- Keep the diff focused.
- Verify security at the owning boundary.
- Preserve API, data, chart, image, and deployment compatibility.
- Run repository-required checks.
- Review exact candidate diff, migrations, secrets, manifests, and test gaps.
- Prepare an evidence packet with skips, residual risk, and rollback.

An independent review request is an external action and requires its own
authorization.
