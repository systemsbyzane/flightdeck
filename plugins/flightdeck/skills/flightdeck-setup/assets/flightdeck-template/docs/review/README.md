# Codex Review Readiness

Use these docs before opening or updating a PR that must pass GitHub
`@codex review`.

- `change-review.md` - findings-first review of an exact diff, branch, working
  tree, plan, architecture, or readiness target.
- `codex-review-readiness.md` - cross-repo preflight before requesting review.
- `backend-review-guidelines.md` - backend patterns likely to produce serious
  review findings.
- `frontend-review-guidelines.md` - frontend patterns likely to produce serious
  review findings.
- `charts-review-guidelines.md` - Helm/YAML and rendered manifest review risks.
- `patching-review-guidelines.md` - image patching review risks.
- `pr-evidence-packet.md` - concise PR evidence template.

GitHub `@codex review` follows the owning repo's `AGENTS.md`. Put mandatory
review expectations in the repo `AGENTS.md` under `Review guidelines`; use these
hub docs as the local preflight and source material.
