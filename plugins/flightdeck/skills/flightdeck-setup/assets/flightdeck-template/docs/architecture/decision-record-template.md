# Architecture Decision Record Template

Use this for decisions that should survive the current thread, PR, or branch.

## Title

`YYYY-MM-DD short decision title`

## Status

Proposed, accepted, replaced, or rejected.

## Context

Describe the problem, affected repos, constraints, and evidence. Include links
or paths to relevant files, workflow runs, issue threads, scan artifacts, or
cluster observations.

## Decision

State the decision directly. Include the owning repo and the layer that owns the
behavior.

## Alternatives Considered

List the serious alternatives and why they were not chosen.

## Security And Compliance Impact

Describe effects on auth, tenancy, secrets, image provenance, dependency risk,
auditability, STIG controls, compliance reporting, or customer deployment
constraints.

## Validation

List the commands, CI checks, scans, cluster checks, or review steps that prove
the decision is implemented correctly.

## Consequences

State follow-up work, migration cost, rollback path, operational impact, and
known risks.
