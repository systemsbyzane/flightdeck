# Evidence analysis

For every conclusion, record the evidence identifier, source path or locator,
collection date, scope, applicable control or requirement, and analyst notes.
State whether the conclusion is observed, inferred, unknown, or not applicable.

Missing evidence is a gap, not proof of failure. A policy statement is design
evidence; it is not operating-effectiveness evidence unless execution records
support it. Preserve originals and place normalized indexes in `evidence-index/`.
