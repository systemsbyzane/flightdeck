# POA&M candidate guidance

A POA&M candidate is a review input, not an accepted risk or closed finding.
Include a stable identifier, source finding, affected scope, evidence references,
proposed remediation, owner if known, target date if authorized, and unknowns.

Never invent owners, dates, milestones, effectiveness, authorization, risk
acceptance, or closure. Mark unverified fields explicitly. Produce same-basename
JSON and YAML sidecars and verify semantic parity before review.
