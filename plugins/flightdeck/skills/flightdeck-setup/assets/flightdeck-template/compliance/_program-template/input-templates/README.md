# Input template drop zone

Place original workbooks, forms, and import templates here. Before writing:

- inventory sheets, hidden sheets, formulas, merges, validation, protection,
  identifiers, controlled fields, and intended response columns;
- preserve the original;
- write only to a new polished output under `deliverables/`;
- keep change summaries, structured records, renderings, and validation results
  under `working-records/`;
- replace every template variable before delivery;
- never claim upload or import acceptance without actual validation evidence.
